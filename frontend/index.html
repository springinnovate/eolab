    Rendering detail

    Adaptive bounded raster detail Broad views always use one center sample in each sample-grid cell, with 127 cells on the longest displayed edge and an aspect-preserving shorter edge. Once the visible source window satisfies strict server-owned limits, EOLab automatically replaces that grid with a complete bounded source-window read reprojected for the map at the same dimensions.

    Sample grids use smooth display interpolation; exact close-view windows use crisp nearest-neighbor presentation. This overview-limited raster is never published to GeoServer.
